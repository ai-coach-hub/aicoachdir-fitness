# Fitness Workout + Video Preview

This branch adds a non-production preview of the workout-building and exercise-video architecture.

Preview routes:
- /fitness/my-workouts
- /fitness/workout-builder
- /fitness/exercise-library

The preview uses a representative subset of the larger exercise blueprint so the UI and workflow can be validated before the full catalog/media library is promoted.

Nothing here changes the production homepage, signup flow, Terms acceptance, Clerk login, Neon records, or subscription handling.
